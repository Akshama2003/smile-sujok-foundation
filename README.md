# Smile Su-Jok Foundation — website

React + TypeScript + Vite + Tailwind + lucide-react, in the NovaAI cinematic scroll-video style.

    npm install
    npm run dev      # local
    npm run build    # production build in dist/

Pages (hash routes): `#/` Home, `#/learn` Know & Learn Sujok, `#/donate` Donate.
All copy/images live in `src/data.ts`. Images and drive videos are hot-linked from the old Vercel site.
The donation form has no payment gateway connected yet.
